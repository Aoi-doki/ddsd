# Doki Doki Second Draft: website

The website for **Doki Doki Second Draft**, a free, wholesome fan mod for Doki Doki Literature Club!
Live at https://aoi-doki.github.io/ddsd/

Plain HTML/CSS/JS, no build step: edit and push.
- `index.html`: home (clubroom hero, Sayori's letter, trailers, club, features, screenshots, roadmap, news)
- `install.html`: Windows / Android / manual install guides + FAQ (`#windows`, `#android`, `#manual`)
- `style.css`, `script.js`: shared by both pages. Download buttons point at
  `github.com/Aoi-doki/ddsd-releases/releases/latest/download/<file>` and read the version and sizes from GitHub's API.
- `assets/`: images and videos (web-sized copies of promo art; `assets/install/` = guide screenshots)

Doki Doki Second Draft is a Doki Doki Literature Club fan game that is not affiliated with Team Salvato.
It is designed to be played only after the official game has been completed.
You can download Doki Doki Literature Club at: https://ddlc.moe
